# Program Implementation Plan

**Goal:** One Anchor program, `hidden_hand`, that deals sealed hands with VRF inside the Private ER, runs a linear-impact market on the ER, reveals at the bell, settles, commits/undelegates, and pays the pot on the base layer.
**Architecture:** An Anchor 1.0.2 workspace under `program/` with a pure-Rust `engine` crate (cards, quote, P&L, winner; golden vectors shared with TS) and the program crate. Every build and test runs inside WSL `Ubuntu-24.04` on the WSL filesystem through `program/scripts/wsl-build.sh`; the Windows clone stays the only source of truth.
**Tech Stack:** Anchor 1.0.2 (`anchor-lang = "1.0.2"`), Agave/Solana 3.1.9 (`solana_version = "3.1.9"` under `[toolchain]`), Rust 1.89.0, `ephemeral-rollups-sdk = "=0.18.0"` (features `anchor`, `access-control`, `vrf`), `serde = "1"` + `serde_json = "1"` (engine dev-dependencies), WSL `Ubuntu-24.04` (user root), `rsync`.
**Source spec:** docs/superpowers/specs/2026-11-26-hidden-hand-design.md

Context for this task (everything you need; you have no other docs):
- **Where things run.** The repo is checked out on Windows at a path that contains a space. You never build there. Every Rust build/test runs inside WSL through `program/scripts/wsl-build.sh`, invoked from **PowerShell at the repo root** with `wsl -d Ubuntu-24.04 -u root --exec bash -l program/scripts/wsl-build.sh <mode>`. The script copies `program/` to `/root/hidden-hand/program` (WSL filesystem) and builds there. Quote every path in the script. WSL's PATH comes from `/root/.toolchain_env` (Agave 3.1.9, anchor-cli 1.0.2, Rust 1.89.0 default).
- **Program keypair.** One fixed keypair at `/root/.config/hidden-hand/program-keypair.json` inside WSL (outside every repo). The build script creates it once with `solana-keygen new --no-bip39-passphrase --silent` and never prints it; only its public key (the program ID) is printed. `sync-id` rewrites `declare_id!` in `lib.rs` and `[programs.devnet]` in `Anchor.toml` (in the Windows source) to that ID. The program ID is a public identifier and fine to commit.
- **SDK 0.18.0 names (verified from the crate source):** `ephemeral_rollups_sdk::access_control::instructions::{CreateEphemeralPermissionCpi, UpdateEphemeralPermissionCpi}`; `ephemeral_rollups_sdk::access_control::structs::{EphemeralMembersArgs { is_private: bool, members: Vec<Member> }, EphemeralPermission::size_of(members: usize), Member { flags: u8, pubkey: Pubkey }, AUTHORITY_FLAG, TX_LOGS_FLAG}`; `CreateEphemeralPermissionCpi { permissioned_account, permission, payer, vault, magic_program, permission_program, args }.invoke_signed(..)`; `UpdateEphemeralPermissionCpi { permissioned_account, permission, payer, authority, vault, magic_program, permission_program, authority_is_signer, args }.invoke_signed(..)`; `ephemeral_rollups_sdk::ephemeral_accounts::rent(data_len: u32) -> u64`; `ephemeral_rollups_sdk::consts::{EPHEMERAL_VAULT_ID, MAGIC_PROGRAM_ID, PERMISSION_PROGRAM_ID}`; `ephemeral_rollups_sdk::vrf::consts::{program_identity_pubkey, DEFAULT_EPHEMERAL_QUEUE}`; `ephemeral_rollups_sdk::vrf::instructions::{create_request_randomness_ix_const, RequestRandomnessParams { payer, oracle_queue, callback_program_id, callback_discriminator, accounts_metas, caller_seed, callback_args }}`; `ephemeral_rollups_sdk::vrf::types::SerializableAccountMeta { pubkey, is_signer, is_writable }`; attribute macros `ephemeral_rollups_sdk::anchor::{ephemeral, delegate, commit, vrf, vrf_callback}`; `#[vrf]` adds `invoke_signed_vrf(&payer, &ix)` to the context; `#[vrf_callback]` injects the `vrf_program_identity` signer check (never declare your own identity field: it breaks with Anchor error 2012).
- **Gotchas.** `Table` is ~2.5 KB: always hold it as `Box<Account<'info, Table>>` (stack limit). Anchor 1.0's `CpiContext::new` takes the program **Pubkey** (`ctx.accounts.system_program.key()`). A freshly `init`-ed account is zeroed, so only set non-zero fields (never assign the 128-entry trade array). If the first `anchor build` rewrites `declare_id!` in the WSL copy, the gate's `declare_id` check fails loudly; run `sync-id`.

//! Hidden Hand engine: pure integer math shared by the program and mirrored by client/src/engine.ts.

pub const SEATS: usize = 4;
pub const CARDS_PER_SEAT: usize = 2;
pub const CARD_COUNT: usize = SEATS * CARDS_PER_SEAT;
pub const CARD_MAX: u8 = 15;
pub const START_PRICE_C: u32 = 6400;

/// Card i = 1 + (randomness[i] % 15), i in 0..8. Seat s holds cards 2s and 2s+1.
pub fn cards_from_randomness(randomness: &[u8; 32]) -> [u8; CARD_COUNT] {
    let mut cards = [0u8; CARD_COUNT];
    for i in 0..CARD_COUNT {
        cards[i] = 1 + randomness[i] % CARD_MAX;
    }
    cards
}

pub fn hidden_sum(cards: &[u8; CARD_COUNT]) -> u16 {
    cards.iter().map(|c| *c as u16).sum()
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn cards_come_from_the_first_eight_bytes() {
        let mut r = [0u8; 32];

        assert_eq!(hidden_sum(&[1, 2, 3, 4, 5, 6, 7, 8]), 36);

#![allow(unused_imports)]
#![allow(unexpected_cfgs)]

use anchor_lang::prelude::*;
use anchor_lang::system_program::{transfer, Transfer};
use ephemeral_rollups_sdk::access_control::instructions::{
    CreateEphemeralPermissionCpi, UpdateEphemeralPermissionCpi,
};
use ephemeral_rollups_sdk::access_control::structs::{
    EphemeralMembersArgs, EphemeralPermission, Member, AUTHORITY_FLAG, TX_LOGS_FLAG,
};
use ephemeral_rollups_sdk::anchor::{commit, delegate, ephemeral, vrf, vrf_callback};
use ephemeral_rollups_sdk::consts::{EPHEMERAL_VAULT_ID, MAGIC_PROGRAM_ID, PERMISSION_PROGRAM_ID};
use ephemeral_rollups_sdk::cpi::DelegateConfig;
use ephemeral_rollups_sdk::ephem::MagicIntentBundleBuilder;
use ephemeral_rollups_sdk::vrf::consts::{program_identity_pubkey, DEFAULT_EPHEMERAL_QUEUE};
use ephemeral_rollups_sdk::vrf::instructions::{
    create_request_randomness_ix_const, RequestRandomnessParams,
};
use ephemeral_rollups_sdk::vrf::types::SerializableAccountMeta;
use hidden_hand_engine::{cards_from_randomness, hidden_sum, CARD_COUNT, SEATS, START_PRICE_C};

pub mod errors;
pub mod state;

pub use errors::HhError;
pub use state::*;

declare_id!("11111111111111111111111111111111");

/// Scoped VRF identity of this program; the oracle signs our callbacks with it.
pub const PROGRAM_IDENTITY: Pubkey = program_identity_pubkey(&crate::ID);

#[ephemeral]
#[program]
pub mod hidden_hand {
    use super::*;

    /// Base layer. Create a table; TEE tables pre-fund the rent of their public permission.
    pub fn open_table(
        ctx: Context<OpenTable>,
        round_id: u64,
        mode: DealMode,
        duration_secs: u16,
        entry_lamports: u64,
    ) -> Result<()> {
        require!(
            duration_secs >= MIN_DURATION_SECS && duration_secs <= MAX_DURATION_SECS,
            HhError::BadDuration
        );
        if mode == DealMode::Tee {
            transfer(
                CpiContext::new(
                    ctx.accounts.system_program.key(),
                    Transfer {
                        from: ctx.accounts.authority.to_account_info(),
                        to: ctx.accounts.table.to_account_info(),
                    },
                ),
                ephemeral_rollups_sdk::ephemeral_accounts::rent(EphemeralPermission::size_of(0) as u32),
            )?;
        }
        let authority = ctx.accounts.authority.key();
        let table = &mut ctx.accounts.table;
        table.round_id = round_id;
        table.authority = authority;
        table.mode = mode;
        table.phase = Phase::Open;
        table.duration_secs = duration_secs;
        table.entry_lamports = entry_lamports;
        table.seat_count = 0;
        table.price_c = START_PRICE_C;
        table.winner = NO_WINNER;
        msg!("hh:open round={} mode={:?} duration={}", round_id, mode, duration_secs);
        Ok(())
    }

    /// Base layer. Take the next seat: pay the entry into the vault, create the hand.
    pub fn join_table(ctx: Context<JoinTable>, commitment: [u8; 32]) -> Result<()> {
        let player = ctx.accounts.player.key();
        let hand_key = ctx.accounts.hand.key();
        let table_key = ctx.accounts.table.key();
        let phase = ctx.accounts.table.phase;
        let mode = ctx.accounts.table.mode;
        let entry = ctx.accounts.table.entry_lamports;
        let n = ctx.accounts.table.seat_count as usize;
        require!(phase == Phase::Open, HhError::WrongPhase);
        require!(n < SEATS, HhError::TableFull);
        require!(
            !ctx.accounts.table.seats[..n].iter().any(|s| s.owner == player),
            HhError::AlreadySeated
        );
        if entry > 0 {
            transfer(
                CpiContext::new(
                    ctx.accounts.system_program.key(),
                    Transfer {
                        from: ctx.accounts.player.to_account_info(),
                        to: ctx.accounts.vault.to_account_info(),
                    },
                ),
                entry,
            )?;
        }
        if mode == DealMode::Tee {
            transfer(
                CpiContext::new(
                    ctx.accounts.system_program.key(),
                    Transfer {
                        from: ctx.accounts.player.to_account_info(),
                        to: ctx.accounts.hand.to_account_info(),
                    },
                ),
                ephemeral_rollups_sdk::ephemeral_accounts::rent(EphemeralPermission::size_of(1) as u32),
            )?;
        }
        let hand = &mut ctx.accounts.hand;
        hand.table = table_key;
        hand.owner = player;
        hand.seat = n as u8;
        hand.cards = [0, 0];
        hand.dealt = false;
        let table = &mut ctx.accounts.table;
        table.seats[n] = Seat {
            owner: player,
            hand: hand_key,
            cash_c: 0,
            pos: 0,
            commitment,
            revealed: false,
        };
        table.seat_count = (n + 1) as u8;
        msg!("hh:join round={} seat={} owner={}", table.round_id, n, player);
        Ok(())
    }

    /// Base layer. Delegate the table or a hand to the ER validator passed as `validator`.
    pub fn delegate_pda(ctx: Context<DelegatePda>, target: DelegateTarget) -> Result<()> {
        let seeds = target_seeds(&target);
        let seed_refs: Vec<&[u8]> = seeds.iter().map(|s| s.as_slice()).collect();
        let validator = ctx.accounts.validator.as_ref().map(|v| v.key());
        ctx.accounts.delegate_pda(
            &ctx.accounts.payer,
            &seed_refs,
            DelegateConfig {
                validator,
                ..Default::default()
            },
        )?;
        Ok(())
    }

    /// ER (TEE). Make the table readable by anyone holding a TEE auth token. Idempotent.
    pub fn create_table_permission(ctx: Context<CreateTablePermission>) -> Result<()> {
        if ctx.accounts.permission.lamports() > 0 {
            return Ok(());
        }
        let round = ctx.accounts.table.round_id.to_le_bytes();

    /// ER (TEE). Make one hand private to its owner. Members come from the account, never from args. Idempotent.
    pub fn create_hand_permission(ctx: Context<CreateHandPermission>, owner: Pubkey) -> Result<()> {

    /// ER. One VRF request deals every seat (queue: DEFAULT_EPHEMERAL_QUEUE).
    pub fn request_deal(ctx: Context<RequestDeal>, client_seed: u8) -> Result<()> {
        let table_key = ctx.accounts.table.key();
        let callback_discriminator = {
            let table = &mut ctx.accounts.table;
            require!(table.phase == Phase::Open, HhError::WrongPhase);
            require!(table.seat_count as usize == SEATS, HhError::TableNotFull);
            table.phase = Phase::Dealing;
            match table.mode {
                DealMode::Tee => instruction::CallbackDeal::DISCRIMINATOR.to_vec(),
                DealMode::CommitReveal => return err!(HhError::ModeNotSupported),
            }
        };
        let mut metas = vec![SerializableAccountMeta {
            pubkey: table_key,
            is_signer: false,
            is_writable: true,
        }];
        for seat in ctx.accounts.table.seats.iter() {
            metas.push(SerializableAccountMeta {
                pubkey: seat.hand,
                is_signer: false,
                is_writable: true,
            });
        }
        let ix = create_request_randomness_ix_const(
            RequestRandomnessParams {
                payer: ctx.accounts.payer.key(),
                oracle_queue: ctx.accounts.oracle_queue.key(),
                callback_program_id: crate::ID,
                callback_discriminator,
                accounts_metas: Some(metas),
                caller_seed: [client_seed; 32],
                callback_args: None,
            },
            PROGRAM_IDENTITY,
        );
        ctx.accounts.table.exit(&crate::ID)?;
        ctx.accounts
            .invoke_signed_vrf(&ctx.accounts.payer.to_account_info(), &ix)?;
        msg!("hh:deal-requested round={}", ctx.accounts.table.round_id);
        Ok(())
    }

    /// ER (VRF callback, TEE mode). Two cards into each private hand; the clock starts.
    pub fn callback_deal(ctx: Context<CallbackDeal>, randomness: [u8; 32]) -> Result<()> {
        let accounts = &mut ctx.accounts;
        require!(accounts.table.phase == Phase::Dealing, HhError::WrongPhase);
        require!(accounts.table.mode == DealMode::Tee, HhError::ModeNotSupported);
        let cards = cards_from_randomness(&randomness);
        let expected = [
            accounts.table.seats[0].hand,
            accounts.table.seats[1].hand,
            accounts.table.seats[2].hand,
            accounts.table.seats[3].hand,
        ];
        let hands = [
            &mut accounts.hand0,
            &mut accounts.hand1,
            &mut accounts.hand2,
            &mut accounts.hand3,
        ];
        for (i, hand) in hands.into_iter().enumerate() {
            require_keys_eq!(hand.key(), expected[i], HhError::WrongHand);
            hand.cards = [cards[2 * i], cards[2 * i + 1]];
            hand.dealt = true;
        }
        let now = Clock::get()?.unix_timestamp;
        let table = &mut accounts.table;
        table.start_ts = now;
        table.end_ts = now + table.duration_secs as i64;
        table.phase = Phase::Trading;
        msg!("hh:dealt round={} end_ts={}", table.round_id, table.end_ts);
        Ok(())
    }

    /// ER (TEE). After the bell: copy every hand to the table and flip every hand permission public.
    pub fn reveal_hands(ctx: Context<RevealHands>) -> Result<()> {
        let now = Clock::get()?.unix_timestamp;
        require!(ctx.accounts.table.mode == DealMode::Tee, HhError::ModeNotSupported);
        require!(ctx.accounts.table.phase == Phase::Trading, HhError::WrongPhase);
        require!(now >= ctx.accounts.table.end_ts, HhError::BellNotRung);
        let table_key = ctx.accounts.table.key();
        let bumps = [ctx.bumps.hand0, ctx.bumps.hand1, ctx.bumps.hand2, ctx.bumps.hand3];
        let owners = [
            ctx.accounts.hand0.owner,
            ctx.accounts.hand1.owner,
            ctx.accounts.hand2.owner,
            ctx.accounts.hand3.owner,
        ];
        let hand_cards = [
            ctx.accounts.hand0.cards,
            ctx.accounts.hand1.cards,
            ctx.accounts.hand2.cards,
            ctx.accounts.hand3.cards,
        ];
        let hands = [
            ctx.accounts.hand0.to_account_info(),
            ctx.accounts.hand1.to_account_info(),
            ctx.accounts.hand2.to_account_info(),
            ctx.accounts.hand3.to_account_info(),
        ];
        let perms = [
            ctx.accounts.permission0.to_account_info(),
            ctx.accounts.permission1.to_account_info(),
            ctx.accounts.permission2.to_account_info(),
            ctx.accounts.permission3.to_account_info(),
        ];
        let mut cards = [0u8; CARD_COUNT];
        for i in 0..SEATS {
            cards[2 * i] = hand_cards[i][0];
            cards[2 * i + 1] = hand_cards[i][1];
        }
        for i in 0..SEATS {
            UpdateEphemeralPermissionCpi {
                permissioned_account: hands[i].clone(),
                permission: perms[i].clone(),
                payer: hands[i].clone(),
                authority: hands[i].clone(),
                vault: ctx.accounts.ephemeral_vault.to_account_info(),
                magic_program: ctx.accounts.magic_program.to_account_info(),
                permission_program: ctx.accounts.permission_program.to_account_info(),
                authority_is_signer: false,
                args: EphemeralMembersArgs {
                    is_private: false,
                    members: vec![],
                },
            }
            .invoke_signed(&[&[HAND_SEED, table_key.as_ref(), owners[i].as_ref(), &[bumps[i]]]])?;
        }
        let table = &mut ctx.accounts.table;
        table.cards = cards;
        table.hidden_sum = hidden_sum(&cards);
        table.phase = Phase::Revealed;
        msg!("hh:revealed round={} hidden_sum={}", table.round_id, table.hidden_sum);
        Ok(())
    }

pub const STEP_C: u32 = 100;
pub const MAX_LOT: u8 = 5;
pub const POS_CAP: i32 = 15;
pub const MIN_PRICE_C: u32 = 800;
pub const MAX_PRICE_C: u32 = 12000;

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Side {
    Buy,
    Sell,
}

impl Side {
    pub fn from_u8(v: u8) -> Option<Side> {
        match v {
            0 => Some(Side::Buy),
            1 => Some(Side::Sell),
            _ => None,
        }
    }
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum TradeError {
    LotSize,
    PositionCap,
    PriceBound,
}

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct Fill {
    pub price_after_c: u32,
    pub cash_delta_c: i64,
    pub pos_delta: i32,
}

/// Linear-impact market maker: one contract moves the price STEP_C cents; a lot fills at the midpoint of its move.
pub fn quote(price_c: u32, pos: i32, side: Side, qty: u8) -> Result<Fill, TradeError> {
    if qty < 1 || qty > MAX_LOT {
        return Err(TradeError::LotSize);
    }
    let q = qty as i64;
    let p = price_c as i64;
    let impact = (STEP_C as i64) * q * q / 2;
    match side {
        Side::Buy => {
            if pos + qty as i32 > POS_CAP {
                return Err(TradeError::PositionCap);
            }
            let after = p + STEP_C as i64 * q;
            if after > MAX_PRICE_C as i64 {
                return Err(TradeError::PriceBound);
            }
            Ok(Fill { price_after_c: after as u32, cash_delta_c: -(q * p + impact), pos_delta: qty as i32 })
        }
        Side::Sell => {
            if pos - (qty as i32) < -POS_CAP {
                return Err(TradeError::PositionCap);
            }
            let after = p - STEP_C as i64 * q;
            if after < MIN_PRICE_C as i64 {
                return Err(TradeError::PriceBound);
            }
            Ok(Fill { price_after_c: after as u32, cash_delta_c: q * p - impact, pos_delta: -(qty as i32) })
        }
    }
}

pub fn pnl_c(cash_c: i64, pos: i32, hidden_sum: u16) -> i64 {
    cash_c + pos as i64 * hidden_sum as i64 * 100
}

/// Highest P&L wins; ties go to the lowest seat.
pub fn winner(pnls: &[i64; SEATS]) -> u8 {
    let mut best = 0usize;
    for i in 1..SEATS {
        if pnls[i] > pnls[best] {
            best = i;
        }
    }
    best as u8
}
